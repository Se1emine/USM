# Интерактивный анализ рынка автомобилей в Молдове

Данный проект представляет собой интерактивный аналитический отчет, выполненный в рамках индивидуальной работы №2 по курсу «Методы статистического анализа данных».

## ⚡ Быстрый запуск для другого человека

Если вы скачали этот проект и хотите сразу увидеть результат:

1.  Установите **Quarto CLI**: [quarto.org](https://quarto.org/docs/get-started/)
2.  Откройте терминал в папке проекта.
3.  Введите команду:
    ```bash
    quarto preview src/Lucrare_Individuala_2_Cars_Moldova.qmd
    ```
4.  Ваш браузер автоматически откроет страницу с интерактивным дашбордом.

## 🛠 Технологический стек

*   **Фреймворк**: Quarto
*   **Логика и вычисления**: Observable JS (OJS)
*   **Загрузка данных**: D3.js (обработка `dataset/cars.csv`)
*   **Статистика**: jStat (регрессионные модели, корреляции)
*   **Визуализация**: Plotly.js (интерактивные графики)
*   **Интерфейс**: Custom HTML/CSS (Glassmorphism design)

## 📊 Основной функционал

Проект реализует полный цикл анализа данных о машинах:

1.  **Предобработка данных**:
    *   Автоматическая типизация и очистка от аномалий (фильтрация нереалистичных цен, пробегов и годов выпуска).
    *   Обработка пропусков и подготовка категориальных признаков.

2.  **Исследовательский анализ (EDA)**:
    *   Интерактивная фильтрация данных по маркам автомобилей.
    *   Динамические графики распределения цен и зависимости стоимости от года выпуска.

3.  **Статистическое моделирование**:
    *   **Множественная линейная регрессия**: Прогнозирование логарифма цены на основе года, пробега и объема двигателя с расчетом $R^2$.
    *   **Логистическая регрессия**: Интерактивный расчет вероятности принадлежности автомобиля к категории «Премиум».
    *   **ANOVA**: Дисперсионный анализ цен в зависимости от типа используемого топлива.

4.  **Снижение размерности (PCA)**:
    *   Построение тепловой карты корреляционной матрицы для выявления скрытых связей между основными характеристиками (Year, Distance, Engine, Price).

5.  **Интерактивный прогноз**:
    *   Пользовательские слайдеры для мгновенной оценки рыночной стоимости автомобиля по заданным параметрам.
