# Dota 2 Statistical Analytics Dashboard

Интерактивный дашборд и статистический отчет для анализа профессиональных матчей Dota 2. Построен с использованием **Quarto** и **Observable JS (OJS)**.

## ⚡ Быстрый запуск для другого человека

Если вы скачали этот проект и хотите сразу увидеть результат:

1.  Установите **Quarto CLI**: [quarto.org](https://quarto.org/docs/get-started/)
2.  Откройте терминал в папке проекта.
3.  Введите команду:
    ```bash
    quarto preview Lucrare_Individuala_1_Dota2.qmd
    ```
4.  Ваш браузер автоматически откроет страницу с интерактивным дашбордом.

---

## 📋 Основной функционал

### 1. Статистический анализ (Разделы 1–7)
- Описательная статистика, доверительные интервалы и проверка гипотез (Z-test, ANOVA) для 83 000 матчей.
- Анализ влияния формата встреч (Bo1, Bo3, Bo5) на количество сыгранных карт.
- **Обновлено**: Исправлен Scatter Plot (2.2.6), теперь с применением *jittering* для визуализации плотности счетов.

### 2. Поиск по командам (Раздел 8)
- Мгновенный поиск любой команды по названию.
- Автоматическая агрегация данных (решен вопрос с разными ID для одной команды, например, Team Liquid).
- Статистика винрейта, топ оппонентов и история по турнирам.

### 3. Анализ игроков (Раздел 9)
- Поиск любого игрока по никнейму.
- Анализ карьерной формы (скользящий винрейт).
- История выступлений за разные команды и поиск самых синергичных напарников.

## 🛠 Технические требования

1.  **Quarto CLI**: Для запуска и рендеринга.
2.  **Браузер**: Chrome, Edge или Firefox (необходим для работы JavaScript-графиков Plotly и D3).
3.  **VS Code + Quarto Extension** (рекомендуется): Для удобного редактирования.

## 🗂 Структура данных
Все данные должны находиться в папке `dataset/`:
- `all_tiers_games.csv` — основной массив матчей.
- `players.csv`, `teams.csv`, `tournaments.csv` — внешние словари для связывания ID с именами.

## 📝 Как сохранить в PDF
Поскольку отчет использует интерактивные JS-элементы, прямой рендеринг в PDF может пропустить графики. **Рекомендуемый способ:**
1.  Запустите `quarto preview` или `quarto render` (в HTML).
2.  Откройте результат в браузере.
3.  Нажмите `Ctrl+P` -> **Сохранить как PDF**. Это гарантирует, что все графики будут отрисованы корректно.
